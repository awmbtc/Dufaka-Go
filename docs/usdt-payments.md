# USDT TRC20 支付

小店复用 GoToAI 已运行的 USDT TRC20 账单服务，不走 GoToAI 用户充值/余额接口。

配置仅在服务端：`USDT_PAY_SERVICE_URL=https://gotoai.lol/shop-usdt`、`USDT_PAY_API_SECRET`、`USDT_TRC20_ADDRESS`。Secret 与地址来自既有服务运行配置，不在源码或页面输出密钥。支付渠道标识 `usdt`，收银路由 `/pay/usdt`，接口类型跳转、客户端全部；商户 ID/KEY/PEM 留空。缺少配置时前台不提供该渠道，后台显示配置缺失。

升级前备份数据库，执行 `sql/006_usdt_payments.sql`。该迁移只加订单报价 JSON、轮询时间列与局部索引。启动时也会补齐结构。开启渠道前验证服务 Bearer 鉴权与网络可达。

- 第一次付款请求在订单行锁内建立远端报价并持久化，提交成功才显示收款地址和精确六位小数金额。刷新/多标签页复用同一报价。
- 创建超时可能在远端留一个未展示的账单；重试生成独立随机引用，未持久化的账单不会展示给买家。
- 金额由原服务分配，既有 GoToAI 单与小店单共享唯一金额池。小店不会自行换算或截断金额。
- 只有服务验证已确认链上交易后，小店还会核对账单 ID、订单引用、币种、网络、地址、人民币金额、精确 USDT 金额、期限、交易 ID 与到账时间，再走既有事务发货。
- 浏览器查询与后台任务均可推进到账。已过期订单继续核验 48 小时；晚到付款使用既有缺货/补发机制。每轮最多 100 单、4 并发，轮询时间排序轮转。
- 页面只显示 TRC20；复制成功才提示成功。地址二维码只含地址，买家需填写显示的完整金额。

验证：`DUFAKA_TEST_DATABASE_URL=... go test -race ./...`；新增用例涵盖并发刷新只建一单、晚到付款与幂等发货、错金额/币种/地址/订单/时间拒绝、拒绝跳转携带 Bearer。浏览器夹具可导出 `luna-usdtpay.html`。生产探针不做真实资金转账，实付确认需另行验收。
