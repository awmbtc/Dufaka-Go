# 小店界面约定

2026-09-27 用户确认：前台固定使用旧版 Luna 蓝色主题，保留 Dufaka-Go 自有品牌。后台保留现有 macOS 27 风格，可以修复布局和功能，不能改成 dujiaoka 后台。

- 前台：只保留 Luna 的 layui、蓝色渐变背景、分类卡和商品卡布局。所有前台页面共用这一套样式。
- 手机端（≤768px）标题栏与内层均为 60px，保留在正常文档流中；不得用负底边距将公告或商品内容拉到标题栏下面。平板和电脑标题栏为 72px。
- 手机商品卡片填满列表容器，与筛选控件共用 12px 左右内边距；图片 72px、名称 16px，价格与余量同组排列，批量优惠独立一行，长名称自然换行。
- 前台允许双指缩放；通过 `touch-action: manipulation` 关闭双击页面放大，手机/触控设备的输入框至少 16px，避免 iOS 聚焦自动放大，不设置禁止用户缩放的 viewport。
- 后台：`web/assets/admin/settings.css` 是现有样式来源，侧栏、圆角分组、浅/深/系统外观保持。大表格在容器内部横向滚动。
- 富文本只用于站点公告、页脚、商品详情与购买说明，并经白名单清洗；商品名称和订单数据继续转义。
- 收银页明确区分待付款、过期、到账、处理异常和网络失败；复制只有成功后才显示“已复制”。
- 审核前先加载个人 ux-designer 技能；浏览器验证桌面 1440px、手机 390px，覆盖真实交互，不能只看模板能否编译。
- 复用 `TestExportAuditPages` 可通过 `DUFAKA_AUDIT_OUTPUT` 导出测试页面。业务集成测试用 `DUFAKA_TEST_DATABASE_URL` 指向专用本地测试库；测试自动建立和清理独立 schema。

- 支付方式：官方微信 SVG、原始钱包图标 + `Cldx Pay`（Space Grotesk Medium）、官方 Tether 图标 + USDT支付。图标与文字作为一个整体在卡片中心，不给文字单独设固定宽。电脑（≥1024px、精细指针）为 100×40px 的紧凑卡片；平板自适应等宽、76px 高；手机 ≤575px 单列 76px 高，保留触控尺寸。选中边框、右上勾选与 aria-pressed 同步。
